# PowerBi-Dashboard - GoTogetherRides

A Power BI reporting project for **GoTogetherRides**, a ride-sharing service.

## Contents

- `GoTogetherRides (3).pbix` - the Power BI report
- `GoTogetherRides (1).pdf` - a PDF export for quick viewing without Power BI

## How to view

Open the `.pbix` file in **Power BI Desktop** to explore the report interactively, or open the PDF for a static copy.
